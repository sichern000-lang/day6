## 1. 왜 만들었나요? (기획 의도)

제주에는 신이 만 팔천이라 할 만큼 이야기가 많습니다. 하지만 이야기는 책 속에, 장소는 지도 앱 속에, 내 여행 기록은 사진첩 속에 따로 흩어져 있습니다.
그래서 **읽기 → 찾아가기 → 기록하기**를 한 화면 안에서 이어 보기로 했습니다.

| | |
|---|---|
| **누구에게** | 제주 이야기를 알고 싶은 여행자와 학생, 특히 한국어가 서툰 **외국인 방문자** |
| **어떤 가치** | ① 흩어진 설화 데이터를 한곳에서 읽습니다(번역·발음·용어 풀이 포함). ② 이야기의 무대로 실제 찾아갈 수 있게 날씨·관광지·국가유산·가는 길을 이어 줍니다. ③ 내가 다녀온 곳과 그림·사진·메모를 이야기 위에 더해 **나만의 제주 기록**으로 남깁니다. |
| **차별점** | “이야기가 많은 제주에 **내 이야기를 더한다**.” 신화 속 장소와 내 장소가 같은 지도, 같은 3D 섬 위에 나란히 놓입니다. |

디자인은 제주 들판의 **연한 세이지**와 제주 하늘의 **연한 파랑**을 바탕으로, 색연필로 그린 듯한 선과 종이 메모의 질감을 썼습니다.

## 2. 무엇을 할 수 있나요? (기능 안내)

위쪽 메뉴: **Home · Stories · Story Map · Island · Notebook · Your Helper · Ask**, 오른쪽에 언어 스위치(KO/EN/ES/DE), **📷 포토부스**, 로그인 버튼이 있습니다.

### 🏠 Home
- 처음 들어오면 종이 메모들이 화면을 덮고 있습니다. 스크롤·스와이프·방향키·클릭으로 **2번** 넘기면 히어로 사진이 드러납니다. (건너뛰기 버튼 / `Esc` 가능, 한 번 본 뒤에는 다시 안 나옵니다. 다시 보려면 주소 끝에 `?intro=1`)
- 히어로 문구는 사람이 치듯 **타이핑**됩니다.
- 아래로 스크롤하면 소개 문장(제주 지도 배경) → 대표 이야기 → **Ask 소개(예시 대화가 저절로 재생)** → 하트를 눌러 수첩에 담는 **My Notebook** 섹션이 이어집니다.

### 📚 Stories — 408편 아카이브
- 민담(310편)과 신화(98편)가 접이식 목록으로 나뉘어 있습니다. 제목 줄을 누르면 펼쳐지고, 오른쪽 **드롭다운**으로 분류(도깨비 이야기, 당신화 …)를 고를 수 있습니다.
- 대표 이야기 6편은 그림 카드로 맨 위에 나옵니다. 돋보기 아이콘으로 검색합니다.
- 이야기를 누르면 팝업이 열립니다: 번역된 **핵심어**, 한국어 제목의 **로마자와 발음 듣기**, **이야기의 무대**(관광공사 데이터), **수첩에 담기**, **Find the story online**(웹 검색).

### 🗺️ Story Map — 신화 + 내 이야기
- 실제 제주 지도 위에 **신화 속 장소 6곳**이 핀으로 찍혀 있습니다. 핀에 마우스를 올리면 이름과 주소가 말풍선으로 뜹니다.
- **＋ Add a place**로 내 장소를 더합니다: 이름, 종류(식당·카페·숙소·볼거리·자연·가게·기타), **나의 이야기(메모)**, **주소 검색**(제주 안만 검색), **대표 그림**(손가락·마우스로 그리기).
- 예시 장소 5곳이 미리 들어 있고, 연필 아이콘으로 **수정**, 휴지통으로 **삭제**, 종이비행기 아이콘으로 **가는 길**(택시 기사님께 보여 줄 한국어 주소 카드 + Google/Naver/Kakao 지도 링크)을 열 수 있습니다.

### 🏝️ Island — 3D 제주 섬 (Three.js)
- 낮은 폴리곤으로 만든 제주 섬을 **끌어서 돌리고, 스크롤(핀치)로 확대**합니다. 처음엔 바다에서 섬이 솟아오르고, 가만히 두면 천천히 돕니다.
- 신화 핀과 내 장소 핀이 꽂혀 있고, 눌러서 이야기 카드를 봅니다.
- 섬 곳곳에 **작은 친구들**이 있습니다: 해녀(테왁), 한라봉 밭, 흑돼지, 돌하르방, 조랑말, 올레길(파랑·주황 점선)을 걷는 여행자와 표지판, 고깃배, 뛰어오르는 돌고래, 갈매기, 구름. 눌러 보면 Your Helper의 설명이 나옵니다.
- **Add character**: 돼지·귤·말·고양이·남자·여자 중에 골라 말풍선 한마디를 적고, 섬의 땅을 눌러 세웁니다(최대 5개).
- **Take photo**: 지금 보는 각도 그대로 인스타그램용 4:5 사진을 만들어 저장·공유합니다.

### 📓 Notebook — 내 수첩
- 담은 이야기는 **색색의 메모지**로, 제주어 단어는 **단어 카드**로, 사진은 **폴라로이드**로 흩어져 있고, 옆으로 넘겨 봅니다. 메모지 사이에는 두들 종이 조각이 섞여 있습니다.
- 각 카드에서 **북마크**(앞으로 올라옴), 메모 쓰기, 삭제, **이미지로 공유·저장**(4:5 그림)이 됩니다.
- 오른쪽 위 **View as list**를 누르면 가지런한 격자로 정리됩니다.
- 로그인하면 어느 기기에서나 같은 수첩이 보입니다(로그인 전에는 닉네임 “익명” 수첩).

### 🔤 Your Helper — 제주 용어집
- 본풀이·당·오름·해녀·돌하르방 같은 **제주 문화 용어**와 하영·삼춘·게메·폭삭 속았수다 같은 **제주어** 49개를 쉬운 말로 풀었습니다. (한국어·English·Español·Deutsch)
- 카드마다 로마자, **발음 듣기**, 관련 이야기 찾기, **노트에 담기** 버튼이 있습니다. 분류 필터와 검색도 됩니다.

### 📷 Photo Booth — 3컷 사진
- 폰에서 가운데 버튼을 누르면 **3, 2, 1** 뒤에 3컷이 차례로 찍힙니다(거울처럼 좌우 반전). 전·후면 카메라 전환, 카메라가 없으면 **사진 고르기**.
- **프레임** 4색: 흰색 · 제주 들판(연한 세이지) · 제주 하늘(하늘색) · 제주 바다(진한 남색). 배경에는 랜딩의 두들이 무늬로 깔립니다.
- **필터** 3종(소프트·들판빛·흑백): 선명하지 않게 살짝 번지고 필름 알갱이가 있는 옛 포토부스 느낌입니다.
- **스티커** 23종(홀로그램 별 10 + 제주 스티커 12 + 한라산 소주병 1): 눌러서 붙이고 끌어서 옮기고 크기·회전·삭제. 스티커는 필터 *전에* 올라가서 사진과 같은 질감이 됩니다.
- 완성한 세로 사진 띠를 **저장 / 공유 / 노트에 담기**.

### 💬 Ask — AI 안내자
- 어느 페이지에서나 **Ask** 를 누르면 대화창이 열립니다. “산방산 전설 알려주고 근처 날씨도 알려줘”처럼 물으면 안내자가 **필요한 도구를 스스로 골라** 데이터를 찾아 답합니다.
- 추천 질문은 열 때마다 16개 중 4개가 무작위로 나옵니다.
- 마음에 드는 답은 **수첩에 저장 / 공유**할 수 있습니다.

### 🔐 로그인
- **이메일 · Google · Guest(로그인 없이 계속)** 중에 고릅니다. 로그인하면 수첩·장소·캐릭터가 계정에 묶입니다.

### 🌐 4개 언어
- 한국어 · English · Español · Deutsch. 화면 문구, 이야기 제목 408개, 핵심어 1,702개, 용어 풀이가 모두 미리 번역되어 있어 API 키 없이도 나옵니다. (상단 메뉴는 항상 영어)

### 📱 모바일
- 375px 폭까지 확인했고, 가로 스크롤이 생기지 않도록 맞췄습니다. 포토부스·3D 섬·노트 슬라이더는 터치로 동작합니다.

## 3. 어떻게 동작하나요? (구조)

```
┌─────────────┐   화면(React)    ┌────────────────────┐
│  브라우저   │ ───────────────▶ │  Vercel 서버 함수  │ ──▶ 공공데이터 API (기상청·관광공사·국가유산청·제주도청)
│ (사용자 폰) │                  │      /api/*        │ ──▶ Google Gemini (AI)
└──────┬──────┘                  └────────────────────┘
       │ 공개용 키만 사용
       ▼
┌─────────────┐
│  Supabase   │  수첩·장소·캐릭터(DB) · 사진(Storage) · 로그인(Auth)
└─────────────┘
```

- **비밀 키가 필요한 일**(공공데이터, Gemini)은 모두 서버 함수(`/api`)가 대신 하고, 브라우저에는 결과만 전달합니다.
- **Supabase**는 브라우저에서 공개용(anon) 키로 바로 연결합니다.
- **상태 관리:** 여러 화면이 함께 쓰는 값(닉네임·언어·로그인·수첩·내 장소·안내자 대화·알림)은 전역 상태(`zustand`)에, 입력창·탭·모달처럼 한 화면에서만 쓰는 값은 그 화면의 `useState`에 둡니다.
- **성능:** 무거운 3D 섬(Three.js)과 포토부스는 그 페이지에 들어갈 때만 불러옵니다(lazy loading).

## 4. 사용한 데이터와 API

| API / 데이터 | 무엇을 주나요? | 키 | 위치 |
|---|---|---|---|
| **기상청 단기예보** (공공데이터포털) | 제주시·서귀포시 시간별 날씨 | 필요 | `server/weather.js` |
| **한국관광공사 국문 관광정보** | 이야기의 무대(관광지·주소·좌표) | 필요 | `server/tour.js` |
| **한국관광공사 영문 관광정보** | 영어·스페인어·독일어 화면의 장소 | 필요 | `server/tourEng.js` |
| **국가유산청 국가유산** | 이야기 근처의 문화유산 | 불필요 | `server/heritage.js` |
| **제주도청 설화·신화·민담 OpenAPI** (E07·E08·E09) | 408편의 제목·분류·핵심어 | 불필요 | `server/folk.js` |
| **OpenStreetMap Nominatim** | 내 장소 주소 검색, 좌표→한국어 주소 | 불필요 | `src/lib/places.js` |
| **Google Gemini** | Ask 안내자, 장소·유산 이름 번역 | 필요 | `server/gemini.js` |

> Gemini는 모델이 바쁘거나(503) 한도에 걸리면(429) 다음 모델로 **자동 재시도**합니다. (`gemini-flash-lite-latest` → `gemini-3.5-flash` → `gemini-3.1-flash-lite`, `GEMINI_FALLBACK_MODELS` 로 변경 가능)

## 5. AI 안내자(Ask)는 어떻게 일하나요?

안내자는 질문을 받으면 **도구 4개** 중 필요한 것을 골라 호출하고, 그 결과만 근거로 답합니다.

| 도구 | 하는 일 |
|---|---|
| `get_story` | 이야기 데이터에서 신화·전설을 찾음 |
| `search_tour_places` | 이야기의 무대가 될 관광지를 찾음 |
| `get_weather` | 제주시·서귀포시의 오늘 날씨를 가져옴 |
| `search_heritage` | 근처 국가유산을 찾음 |

- 한 번 대답하는 동안 **최대 6턴**까지 도구를 이어서 부를 수 있습니다.
- 화면의 답변 말풍선 위에 **어떤 도구를 어떤 값으로 불렀는지(호출 내역)** 가 함께 보입니다.
- **지어내지 않도록** 데이터에 없는 이야기는 없다고 답하게 했습니다.

**직접 해 볼 질문**

| 질문 | 기대하는 동작 |
|---|---|
| “산방산 전설 알려주고, 그 근처 오늘 날씨도 알려줘” | `get_story` → `get_weather` (연속 호출) |
| “오늘 서귀포 날씨 보고 갈 만한 신화 장소 추천해줘” | 날씨 → 이야기 → 장소 |
| “‘황금 바다 용왕과 일곱 돌고래’ 신화 알려줘” | 데이터에 없다고 답함 (지어내기 테스트) |

## 6. 직접 실행해 보기 (설치 가이드)

### 1) 준비물
- Node.js **22.x**, npm
- Vercel CLI (`npm i -g vercel`) — 서버 함수까지 같이 돌리려면 필요
- Supabase 프로젝트, 공공데이터포털(data.go.kr) 인증키, Google AI Studio의 Gemini 키

### 2) 내려받고 설치
```bash
git clone https://github.com/sichern000-lang/day6.git
cd day6
npm install
```

### 3) 환경변수 채우기
```bash
cp .env.example .env.local
```
`.env.local` 에 값을 채웁니다. (이 파일은 git에 올라가지 않습니다)

| 변수 | 어디서 받나요? | 브라우저에 노출? |
|---|---|---|
| `VITE_SUPABASE_URL` | Supabase 대시보드 → Project Settings → API (주소 끝에 `/rest/v1` 은 빼세요) | 예(공개 주소) |
| `VITE_SUPABASE_ANON_KEY` | 같은 곳의 **anon / publishable** 키 (※ secret 키 아님!) | 예(공개용 키) |
| `DATA_GO_KR_KEY` | 공공데이터포털 → 일반 인증키 **Decoding** 키 | **아니오** |
| `TOUR_ENG_KEY`, `TOUR_ENG_BASE` | 영문 관광정보 활용신청 (End Point 는 포털 상세 화면 값) | **아니오** |
| `GEMINI_API_KEY` | Google AI Studio | **아니오** |
| `GEMINI_MODEL`, `GEMINI_FAST_MODEL` | `gemini-flash-lite-latest` 권장 | 아니오 |
| `GEMINI_FALLBACK_MODELS` | (선택) 쉼표로 구분한 대체 모델 | 아니오 |

### 4) Supabase 준비
Supabase 대시보드 → **SQL Editor → New query** 에 아래 파일 내용을 붙여 넣고 **Run** 합니다. 순서대로, 여러 번 실행해도 안전합니다.

| 파일 | 만드는 것 |
|---|---|
| `supabase.sql` | 수첩 표 `saved_stories` (이야기·단어·Ask 답변·메모·북마크) |
| `supabase-places.sql` | 내 장소 표 `my_places` |
| `supabase-characters.sql` | 3D 섬 캐릭터 표 `island_characters` |
| `supabase-photos.sql` | 노트 사진 칸 + 저장소 `notebook-photos` |

> 표가 없어도 앱은 멈추지 않고, 장소·캐릭터는 “이 기기에만 저장” 모드로 동작합니다.

**Google 로그인(선택):** Google Cloud Console → OAuth 클라이언트(웹)를 만들고 *승인된 리디렉션 URI* 에 `https://<프로젝트>.supabase.co/auth/v1/callback` 을 넣은 뒤, Client ID/Secret 을 Supabase → Authentication → Providers → Google 에 입력합니다. Authentication → URL Configuration 에는 로컬과 배포 주소를 Redirect URL 로 추가하세요.

## 8. 보안은 어떻게 지켰나요?

- 비밀 키(Gemini·공공데이터)는 **서버 함수에서만** 쓰고, 브라우저 코드에는 들어가지 않습니다. (`VITE_` 로 시작하는 변수만 브라우저로 갑니다.)
- `.env.local` 은 `.gitignore` 로 git에서 제외했습니다. 저장소에는 값이 빈 `.env.example` 만 있습니다.
- **검증:** 빌드 결과물(`dist`), 추적 중인 모든 파일, 전체 git 이력(36개 커밋)에서 세 비밀 키 값을 검색했을 때 **발견되지 않았습니다.**
- 브라우저에 있는 Supabase 키는 공개용(anon/publishable) 키입니다.
- ⚠️ **학습용 설정 안내:** 지금 Supabase 권한 정책은 “누구나 읽고 쓰기”입니다. 실서비스로 가려면 `owner = auth.uid()` 로 본인 데이터만 다루게 바꾸고, 사진 저장소도 본인 폴더만 쓰게 제한해야 합니다.

## 11. 3분 시연 순서

1. **Home** — 종이 인트로를 2번 넘기고, 타이핑되는 히어로를 보여 줍니다. 하단 섹션에서 하트로 이야기를 수첩에 담습니다.
2. **Stories** — 민담을 펼치고 이야기 팝업(번역된 핵심어, 로마자·발음)을 엽니다.
3. **Story Map** — 신화 핀과 내 장소를 보고, 장소를 하나 추가합니다(주소 검색 + 그림).
4. **Island** — 3D 섬을 돌리고, 해녀·돌하르방을 눌러 설명을 봅니다. 내 캐릭터를 세우고 말풍선을 띄운 뒤 사진을 찍습니다.
5. **Ask** — 연속 호출 질문을 하고 호출 내역을 보여 줍니다. 답변을 수첩에 저장합니다.
6. **Notebook** — 흩어진 메모지를 넘기고 “리스트로 보기”, 카드를 이미지로 공유해 봅니다.
7. **Photo Booth** — 3컷 촬영 → 프레임·필터·스티커 → 저장.

## 12. 문제가 생겼을 때 (FAQ)

| 증상 | 이유와 해결 |
|---|---|
| “서버 응답이 JSON이 아님 … vercel dev 로 실행했는지 확인하세요” | `npm run dev` 는 화면만 띄웁니다. **`vercel dev`** 로 실행하세요. |
| Ask 가 “GEMINI_API_KEY 가 없어요” | `.env.local` 에 키를 넣고 서버를 다시 시작하세요(배포본은 Vercel 환경변수 + 재배포). |
| Ask 가 가끔 느리거나 “사용량이 많아요” | Gemini가 바쁠 때 다른 모델로 자동 재시도합니다. 그래도 안 되면 잠시 뒤 다시 시도하세요. |

| 스크롤이 섹션 단위로 딱딱 멈춰요 | 랜딩의 의도된 동작입니다(섹션 스냅). |
| 소개 인트로를 다시 보고 싶어요 | 주소 끝에 `?intro=1` 을 붙이세요. |

## 13. 알려진 한계와 앞으로의 계획

**한계**
- 제주도청 OpenAPI는 제목·분류·핵심어만 제공하고 본문 링크가 열리지 않아, **이야기 본문은 대표 6편**에만 있습니다. 나머지는 “Find the story online”(웹 검색)으로 연결합니다.
- 번역(핵심어 1,702개·제목 408개·용어 풀이 49개)은 **AI 초안**이라 제주 고유명사와 제주어는 원어민 검수가 필요합니다.
- Google 검색을 이용한 이야기 요약은 Gemini 유료 요금제가 필요해 넣지 않았습니다.
- 현재 Supabase 권한은 학습용(누구나 읽고 쓰기)입니다.
- 포토부스의 실제 카메라 촬영은 폰에서 확인해야 합니다. 3D 섬은 구형 폰에서 느릴 수 있어 해상도를 낮춰 그립니다.

**앞으로**
- 이야기 본문 확충(출처 검증 후), 이야기와 내 장소를 직접 연결하는 기능
- 로그인한 본인 데이터만 보이게 하는 권한 정책
- 일본어·중국어 추가
- 오프라인에서도 보이는 PWA(홈 화면 추가)
